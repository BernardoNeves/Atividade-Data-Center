# Atividade Data Center

Projeto acadêmico de servidor web utilizando Windows Server 2022, IIS, HTML, CSS e JavaScript.

## Site

**O Kaio Jorge já ganhou um título hoje?**

A página exibe uma contagem automática em anos, meses e dias desde 30/09/2018 e foi publicada em um servidor IIS para a disciplina de Server and Data Center Administration.

## Arquivos

- `index.html` — estrutura da página
- `styles.css` — estilização visual
- `script.js` — contador automático
- `kaio-jorge.jpeg` — imagem utilizada na página

## Ambiente

- Windows Server 2022
- IIS (Internet Information Services)
- Oracle VirtualBox
- HTML, CSS e JavaScript
